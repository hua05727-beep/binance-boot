# media

The boot videos are not stored in this git clone. They ship as GitHub Release assets on tag **v1.0.0**:

- `startup.mp4` — 25-second boot video with music
- `startup_nomusic.mp4` — same picture, effects only (no music bed)

Download both files from the [v1.0.0 release](https://github.com/hua05727-beep/binance-boot/releases/tag/v1.0.0) and place them in this directory:

```
media/startup.mp4
media/startup_nomusic.mp4
```
